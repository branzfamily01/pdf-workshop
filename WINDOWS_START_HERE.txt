PDF Workshop - Windows版のはじめかた
==================================

通常利用ではPythonをインストールする必要はありません。

使い方
------
1) GitHub Actionsで作成された PDFWorkshop-Windows-Portable.zip をダウンロードします。
2) ZIPを右クリックして「すべて展開」します。
3) 展開したフォルダの PDFWorkshop.exe をダブルクリックします。
4) アプリが開いたらPDFを画面へドラッグします。

OCRについて
-----------
配布版にはOCR用のTesseractも同梱する構成です。
別途PythonやTesseractを自分でインストールする必要はありません。

最初に試す流れ
-------------
PDF追加 → PDF診断 → 見開き左右分割 → 冊子順→通常順 → クロップ → OCR → PDFを書き出す

開発者向け
---------
setup_windows.bat / run_windows.bat はソースコードから動かす開発用です。
通常利用者は使いません。
