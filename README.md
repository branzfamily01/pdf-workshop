# PDF Workshop MVP

教材PDFをローカルで整理・復元する Windows 向けデスクトップMVPです。

## 実装済み
- PDF/複数PDF読込、ドラッグ&ドロップ
- ページサムネイル
- 回転、除外（非破壊削除）、並べ替え
- A3等の見開き左右分割（50:50 / 左→右・右→左）
- 冊子面付け順 → 通常ページ順（左綴じ標準）
- 上下左右クロップ（mm）
- プロジェクト保存/読込（.pdfwork）
- PDF書き出し
- OCRmyPDFによるOCR（インストール済みの場合、日本語+英語 / rotate / deskew）
- 基本診断（ページ数、横向き、A3相当、OCRなし、見開き候補）

## Windows 起動
1. Python 3.12+ をインストール
2. このフォルダで `setup_windows.bat` を実行
3. `run_windows.bat` を実行

OCRを使う場合は Tesseract 5 をWindowsへインストールし、日本語 `jpn` と英語 `eng` の言語データを有効にしてください。
OCRが利用できない場合でも、PDF整理機能は使用できます。

## 注意
これは仕様 v1.1 に基づくMVP初期実装です。OCR同梱EXE化、見開き境界の画像自動検出、白紙判定、クラッシュ復旧などは次段階です。
